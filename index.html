About / For Admins

Purpose: Educational games and teacher-facing AI tools for classroom activities. No student accounts required. No ads, no third-party trackers.

Security & Privacy

  • All game logic runs in the browser (no user data transmitted).
  • AI features are disabled by default; enabling requires a server-side API key and whitelisted domains.
  • Suggested deployment: GitHub Pages on a school-owned domain or a school-approved host with HTTPS.

How to enable AI (for IT / Admins)

  1. Provide a server-side endpoint that holds an API key; the frontend should call your endpoint (never include keys in client-side JS).
  2. Recommended: create a school account with your chosen provider and restrict usage to the school domain/IPs.
  3. Update the code's sendToAPI() function in script.js to point to your endpoint.
